# maxches99/homebrew-tap

Homebrew casks for [claude-client](https://github.com/maxches99/claude-client).

```bash
brew install --cask maxches99/tap/claude-remote-host
brew upgrade
```

`Casks/claude-remote-host.rb` is rewritten by the release workflow of claude-client on every `v*` tag;
edits here get overwritten.
